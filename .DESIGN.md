## 1. Visual Identity & Aesthetic Philosophy

ApexSMC is designed as an institutional-grade, high-density dark-mode trading workstation. It unites the quantitative rigor and data clarity of high-end Bloomberg/TradingView terminals with the sleek, polished ergonomics of modern engineering tools (Vercel, Linear).

### Core Design Principles
1. **Optical Endurance:** Built on deep obsidian and graphite base layers (`#131519`) that absorb harsh glare during 12+ hour market monitoring sessions.
2. **Surgical Signal Distinction:** High-contrast neon signals—Electric Emerald (`#4CAF88`) for Bullish/Demand and Crimson Red (`#E05C64`) for Bearish/Supply—used strictly for market direction, order flow confirmation, and invalidation points.
3. **Institutional Precision:** Crisp 4px corner roundness (`rounded-sm` / 4px), micro-borders (`#2A303C`), and monospaced numerical typography for exact pip calculation and sub-pip spreads.
4. **Contextual Transparency:** Visual overlays (Fair Value Gaps, Order Blocks, Liquidity Sweeps, BOS rays) maintain 15%–30% opacity to preserve underlying candlestick visibility without visual clutter.

## 3. Typography System

The typography system uses three specialized font families to balance visual impact, user interface clarity, and numerical precision:

```
Headings & Display Tickers: Bebas Neue / Public Sans Bold
UI Navigation & AI Reasoning: Inter
Financial Prices & Metrics:   IBM Plex Mono (or JetBrains Mono)
```

### Typographic Scale
| Style Token | Font Family | Size | Weight | Line Height | Tracking | Usage |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `display-lg` | Bebas Neue | `44px` | 700 | `1.0` | `+0.05em` | Terminal banner, hero pair stats (`EURUSD`) |
| `headline-md` | Inter / Bebas | `20px` | 700 | `1.2` | `-0.01em` | Section titles, strategy header, bias banner |
| `body-md` | Inter | `13px` | 400 | `1.5` | `0` | AI analysis narrative, educational notes |
| `body-sm` | Inter | `12px` | 500 | `1.4` | `0` | Checklist items, card descriptions, labels |
| `mono-price` | IBM Plex Mono | `13px` | 600 | `1.0` | `+0.02em` | Live tick price, bid/ask spread, POI ranges |
| `mono-stat` | IBM Plex Mono | `11px` | 500 | `1.0` | `0` | Pip calculations (`+55 pips`), timestamps, R:R (`1:3.8`) |

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ TOP NAVIGATION BAR: Logo | Ticker Switcher | Timeframes | Session Badge | Snapshot CTA │
├──────┬─────────────────────────────────────────────────┬───────────────────────────────┤
│ SIDE │ CHART VIEWPORT (70%)                            │ AI ANALYSIS SIDEBAR (30%)     │
│ RAIL │ - Live Candlestick & Tick Render (SVG/Canvas)   │ - Strategy Selector (SMC/...) │
│      │ - SMC Overlays: FVG, Order Blocks, BOS, CHoCH   │ - Executive Bias & Confluence │
│      │ - Floating Left Drawing Tools                   │ - Calculated POI / SL / TP    │
│      │ - Monospace Price Scale Axis                    │ - Technical Evidence Checklist│
│      │ - Bottom Time Scale Axis                        │ - Inquire Setup AI Input      │
├──────┴─────────────────────────────────────────────────┴───────────────────────────────┤
│ BOTTOM DRAWER: Recent Saved Analysis Snapshots & Historical Backtest Logs              │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

### Component Details
1. **Top Navigation Bar (`h-14` / 56px):**
   - Brand monogram with emerald glowing border.
   - Quick ticker switcher with live OHLC price & daily delta (`EUR/USD · 1.08642 +0.24%`).
   - Timeframe pills (`M1`, `M5`, `M15`, `H1`, `H4`, `D1`) with active state (`bg-surface text-primary border border-primary/50`).
   - Active Market Session Pill (`London/NY Overlap · Active High Vol` with pulsating green dot).
   - Primary CTA: **Snapshot & Analyze** (`bg-primary text-on-primary font-bold shadow-glow`).
2. **Chart Viewport (70% Width):**
   - High-contrast green wicks (`#4CAF88`) & red wicks (`#E05C64`).
   - Fair Value Gap (FVG) shaded corridor (`url(#fvgGrad)` amber/emerald with dashed borders).
   - Unmitigated Order Block (OB) demand zone with gradient depth.
   - Break of Structure (BOS) dotted ray with anchored badge.
   - Buy-Side Liquidity (BSL) swept arrow flag.
   - Floating left-hand vector drawing toolbar (crosshair, trendline, fibonacci, zone box, measure).
   - High-contrast right-hand price axis showing spread and live flashing price tag.
3. **AI Analysis Intelligence Panel (30% Width):**
   - Strategy switcher: `SMC`, `Chart Patterns`, `Candlestick Reversals`, `Combined Confluence`.
   - **Executive Bias Card:** `BULLISH BIAS` badge with `86% Confluence Score` progress meter.
   - **Calculated Institutional Trade Levels:** POI, Invalidation SL, Targets TP1/TP2, Risk-Reward `1:3.8`.
   - **Confluence Checklist:** 4H Trend Alignment, Liquidity Sweeps, CHoCH validation, FVG rebalance.
   - **Interactive Setup Inquiry:** Input bar with quick prompt suggestions ("What invalidates this setup?", "Explain FVG fill probability").
4. **Bottom Historical Drawer (`h-28` / 112px):**
   - Horizontal scrollable bento cards of past snapshots with pair, timeframe, strategy, and verified outcome status.
